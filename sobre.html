Sobre o projeto

Sobre automação ServiceNow

Uma ferramenta interna para agilizar a abertura de chamados repetitivos no ServiceNow, feita para quem abre o mesmo tipo de registro para várias pessoas ao mesmo tempo.

O que é

Objetivo da automação

A automação ServiceNow nasceu para eliminar o trabalho repetitivo de abrir, um a um, chamados de "Registro de Proatividade" no ServiceNow. Em vez de preencher o mesmo formulário dezenas de vezes, o analista informa a lista de e-mails uma única vez, e a automação cuida do resto — abrindo e preenchendo um chamado para cada pessoa da lista.

Como funciona

Do formulário à abertura do chamado

O analista preenche o formulário na página inicial (e-mails dos usuários, tipo de atendimento e observações) e clica em Enviar Chamados. O site abre uma aba do navegador para cada e-mail informado, apontando para o item de catálogo correspondente no ServiceNow. Um userscript instalado no navegador (via Tampermonkey) lê os dados enviados e preenche automaticamente cada formulário do ServiceNow, restando ao analista apenas revisar e confirmar o envio em cada aba.

Tecnologias utilizadas

O que roda por trás da automação

O site é feito apenas com HTML, CSS e JavaScript — sem servidor ou backend próprio — e roda direto no navegador do analista:

  • Abertura de abas — o próprio navegador (window.open), compatível com Chrome, Edge e Firefox.
  • Tampermonkey — extensão de userscript que preenche automaticamente o formulário do ServiceNow em cada aba.
  • SheetJS — biblioteca usada para ler planilhas .xlsx/.xls importadas com a lista de e-mails.
  • ServiceNow — Catálogo de Serviços, onde os chamados de "Registro de Proatividade" são efetivamente abertos.
