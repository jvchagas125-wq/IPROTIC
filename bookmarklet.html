Alternativa sem extensão

Instalar o bookmarklet de preenchimento

Use esta opção se o Tampermonkey estiver bloqueado pelo administrador do seu computador (mensagem "Seu administrador bloqueou..."). O bookmarklet faz o mesmo preenchimento automático, mas como um favorito do navegador — sem instalar nenhuma extensão.

Diferença importante: o Tampermonkey preenche o formulário sozinho, assim que a aba abre. O bookmarklet precisa de um clique seu em cada aba — funciona igual, só não é 100% automático.

Passo 1 — Instalar

Arraste o botão abaixo para a barra de favoritos

Se a barra de favoritos não estiver visível, pressione Ctrl+Shift+B para exibi-la. Depois, arraste o botão abaixo para dentro dela (não clique — arraste e solte):

⇖ IPROTIC: Preencher ServiceNow

Se o link acima não carregar corretamente, recarregue esta página (o código do bookmarklet é montado via JavaScript ao abrir).

Passo 2 — Usar

Toda vez que abrir os chamados

Na página inicial do IPROTIC, clique em Enviar Chamados normalmente — as abas do ServiceNow vão abrir. Em cada aba, espere o formulário do catálogo carregar e clique no favorito "IPROTIC: Preencher ServiceNow" que você instalou. Os campos serão preenchidos automaticamente; revise e confirme o envio do chamado.
