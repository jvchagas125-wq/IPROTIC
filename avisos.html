Automação 100% automática — agente local Python

Abre e preenche todos os chamados sozinho, direto no clique de "Enviar Chamados"

O iprotic_local_agent.py fica rodando em segundo plano no seu PC. Com ele ativo, basta preencher o formulário e clicar em "Enviar Chamados" normalmente: o site detecta o agente sozinho e os chamados são abertos e preenchidos automaticamente — sem baixar arquivo nenhum e sem rodar nada na hora do envio.

  1. Se ainda não tiver Python instalado no PC, instale o Python 3.14 (64 bits) pelo Portal da Empresa ou seguindo o procedimento da base de conhecimento do ServiceNow — não instale por fora, para não esbarrar na política de instalação da TI.
  2. Instale, uma única vez: pip install playwright e depois playwright install chromium.
  3. Rode python iprotic_local_agent.py (ou dê duplo clique em iniciar_agente_iprotic.bat) e deixe a janela aberta em segundo plano.
  4. Na primeira vez, faça login no ServiceNow na janela que abrir e pressione ENTER no terminal para continuar — as próximas execuções reaproveitam essa sessão salva.
  5. No site, preencha o formulário e clique em "Enviar Chamados" — pronto, sem mais nenhum passo manual.
  6. Revise cada aba aberta e confirme o envio manualmente.

Dica: copie um atalho do iniciar_agente_iprotic.bat para a pasta de Inicialização do Windows (Win+R → shell:startup) para o agente subir sozinho a cada login — só o login do ServiceNow continua manual na primeira vez do dia.

Prefere não deixar nada rodando em segundo plano o tempo todo? Use o botão "Baixar dados (Python)" na página inicial para gerar o arquivo iprotic-chamados.json e rode python automacao_iprotic.py manualmente quando quiser processar um lote.

Consulte o analista responsável pela automação para obter os arquivos iprotic_local_agent.py / automacao_iprotic.py e o passo a passo completo.
