Pontos de atenção para usar a automação sem problemas, e o histórico do que já mudou no site.

Permita pop-ups para este site antes de enviar chamados — como várias abas são abertas de uma vez, Chrome, Edge e Firefox tendem a bloquear parte delas. Veja o aviso completo com o passo a passo de cada navegador na página inicial, logo acima do formulário.
Antes do primeiro uso: instale o Python e as dependências do script automacao_iprotic.py — sem ele, as abas abrem mas os formulários não são preenchidos sozinhos. Veja o passo a passo completo logo abaixo.

Automação 100% automática — script Python

Abre e preenche todos os chamados sozinho

O script automacao_iprotic.py abre e preenche todas as abas sozinho — sem instalar extensão de navegador e sem precisar de nenhum clique manual por aba.

  1. Preencha o formulário na página inicial normalmente e clique em "Baixar dados (Python)" em vez de "Enviar Chamados" — isso baixa o arquivo iprotic-chamados.json.
  2. Instale, uma única vez: pip install playwright e depois playwright install chromium.
  3. Rode: python automacao_iprotic.py caminho\para\iprotic-chamados.json
  4. Na primeira vez, faça login no ServiceNow na janela que abrir e pressione ENTER no terminal para continuar — as próximas execuções reaproveitam essa sessão salva.
  5. Revise cada aba aberta e confirme o envio manualmente.

Consulte o analista responsável pela automação para obter o arquivo automacao_iprotic.py e o passo a passo completo.
