Abertura de Chamados via Automação

Preencha os campos abaixo para configurar a abertura automática de chamados no ServiceNow. Ao enviar, uma aba do navegador é aberta para cada e-mail informado, já com os dados preenchidos no formulário do ServiceNow.

Como funciona: O analista informa os e-mails dos usuários e configura os parâmetros do chamado. Ao clicar em Enviar Chamados, o site abre uma aba do navegador para cada e-mail informado, apontando para o item de catálogo do ServiceNow. Um userscript instalado no navegador (Tampermonkey) preenche automaticamente cada formulário com os dados configurados aqui. Campos marcados com Auto são preenchidos automaticamente pelo sistema.
Importante: como várias abas são abertas de uma vez, o navegador pode bloquear parte delas como pop-up. Permita pop-ups para este site antes de enviar:
Chrome/Edge: clique no ícone de bloqueio de pop-up que aparece na barra de endereço após o primeiro envio, ou acesse chrome://settings/content/popups (Edge: edge://settings/content/popups) e adicione o endereço do site à lista de permitidos.
Firefox: na notificação "Firefox impediu que este site abrisse uma janela pop-up", clique em Preferências → Permitir, ou acesse about:preferences#privacy → Permissões → Bloquear janelas pop-up → Exceções, e adicione o endereço do site.
Se mesmo assim alguma aba for bloqueada, um botão para reabri-la aparecerá abaixo do formulário.
0 aba(s) foram bloqueadas pelo navegador.
